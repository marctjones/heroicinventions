Parts are free for now (#255 undecided). The player IS the rover; a machine run may be operated by a person.
- Never take focus: GUI checks only in hidden windows (tools/gui-check.sh --hidden, the tools/*-gui.sh and *-mouse.sh scripts). Godot is at /Applications/Godot_mono.app/Contents/MacOS/Godot (not on PATH).
- **Worktrees:** work in your own worktree and branch (`git worktree add -b NAME .claude/worktrees/NAME main`), prepared with `PLTCOLLECTS=$PWD/racket: racket racket/build.rkt`, then `cd game && dotnet build && $GODOT --headless --import .` (always set PLTCOLLECTS in a worktree, or the main checkout's heroic package is used silently). With one session running it lands its own work; with two or more, one session (the lead) is the only merger and the others never merge, push or touch other worktrees.
- **Landing:** from a landing copy of the branch (a branch checked out in a worktree can't be rebased from elsewhere): rebase or cherry-pick onto main, rebuild, then the full suite: `racket racket/build.rkt` (git status: no drift), `(cd game && dotnet build)`, `dotnet test tests/HeroicInventions.Sim.Tests`, `raco make racket/heroic/main.rkt && raco test racket/heroic/tests` (about 20 minutes, in the background), and the director's solve (`cd game && HEROIC_WORLD=lonely-rover-opening HEROIC_HINTS=0 HEROIC_INPUT_FILE=routes/lonely-rover-opening/solve.steps HEROIC_QUIT_AFTER_SIM_SECONDS=200000 $GODOT --headless --fixed-fps 30 --path .` must print "sol 3 03:00 win"). Independent branches can land as one batch under one suite. Then `git merge --ff-only`, push, close the issue with worked-vs-measured numbers, remove the worktree. A session whose commits landed with new hashes runs `git rebase main`, never a merge.
